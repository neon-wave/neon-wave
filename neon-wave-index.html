REDEEM CODE

Enter a gift code from the game owner. A valid code unlocks one shop item — an arrow, trail, color or theme — free, no gems needed, and equips it right away. Some codes give gems instead, added straight to your balance.

Every code works 5 times in total, across all players, and only until its expiry day — the owner chooses the number of days (for example 5 or 7) when the code is created. Uses and expiry are counted on the gift server, not on this phone.
